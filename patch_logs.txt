2026-11-11 · Participant view (app/static/participant.html, app/server.py)

Added

    pen sizes, Undo/Clear, palm rejection. No guide, steps or reference.
    No server calls: nothing is logged and levels are untouched. Start

    repeats only the step change, not the probe.

    showApp(), toSetup(), updateGo(). restartPractice() now uses goToLayer().

Tested

    returning participant, /api/layer failure + Try again, Practise again
    failure + retry, new ID, baseline export, no console errors). Test
